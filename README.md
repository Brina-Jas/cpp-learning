# cpp-learning
A public documentation of self-teaching C++ for use in the context of HEP, alongside my third year in BSc Physics at Cardiff University.

In this repository I aim to document multiple projects that demonstrate my growing knowledge in C++, starting as a complete beginner. Projects I hope to experiment with are:
* An N-body gravity simulation
* A Monte Carlo integrator
* A random walk simulation
* A basic particle collision toy model

I would eventually also like to introduce myself to ROOT, machine learning and Graph Neural Networks.
